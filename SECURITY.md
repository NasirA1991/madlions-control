# Security

Madlions Control is a local desktop application. It does not make network
requests, collect telemetry, or run a background service. It talks only to the
vendor HID collection of the connected keyboard.

## Reporting a vulnerability

Please use GitHub's **private vulnerability reporting** for this repository
(Security → Report a vulnerability) instead of opening a public issue. Include
the version, distribution, and enough detail to reproduce the problem.

Please do not include secrets, serial numbers, or full device reports from
machines that are not yours.

## Supported versions

Security fixes are applied to the latest release and to `main`.
